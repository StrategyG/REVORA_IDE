# Security policy

## Supported release line

Only the currently maintained release on the protected default branch will be considered supported once production operations are established. No production release exists in the current foundation branch.

## Reporting a vulnerability

Do not publish exploit details, credentials, personal data or customer source code in public issues. Use GitHub's private vulnerability reporting feature when enabled for this repository, or contact the repository owner through a private channel.

Include the affected commit, impact, reproducible steps, and any safe proof of concept. Do not include live secrets.

## Security posture

The current application is a browser-local foundation preview. Authentication, server persistence, AI, patch application, terminal, build execution and preview runtime are not enabled. This statement is not a security certification.

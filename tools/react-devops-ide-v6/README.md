# React DevOps IDE v6 source package

Extract `react-devops-ide-v6-source.zip` into this `tools/` directory so that this folder contains `package.json`, `server.js`, `public/`, `lib/`, and `workspace/`.

The repository workflow skips v6 validation until `package.json` is present. See [the integration guide](../../docs/integrations/REACT_DEVOPS_IDE_V6.md).
